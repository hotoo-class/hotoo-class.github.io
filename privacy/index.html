개인정보처리방침

시행일: 2026년 11월 8일

이 페이지는 호랑이투자학당(유튜브 채널 '호랑이투자학당', 인스타그램 @hotoo.class)이 운영하는 영상 업로드 도구 '호투 업로더'와 이 기록 사이트(hotoo-class.github.io)에 적용됩니다.

1. 모으는 정보

'호투 업로더'는 채널 운영자 본인의 Google 계정으로만 로그인해, 운영자 채널에 영상을 올리고 댓글을 달고 채널 통계를 읽는 데 YouTube API를 씁니다. 다른 사람의 개인정보를 모으거나 저장하지 않습니다.

이 기록 사이트는 회원가입, 댓글, 쿠키 기반 추적 기능이 없습니다. 화이트/블랙 화면 설정만 방문자 브라우저 안(localStorage)에 저장되며 서버로 보내지지 않습니다.

2. 정보의 이용과 보관

로그인 토큰은 운영자 컴퓨터에만 보관되며 제3자에게 제공하지 않습니다. YouTube API로 받은 데이터는 운영자 채널 관리 목적으로만 씁니다.

3. Google API 서비스 사용자 데이터 정책

'호투 업로더'가 Google API에서 받은 정보의 사용은 Limited Use 요구 사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.
